# Proyecto-Integrador-1: Biblioteca Escolar
**Integrantes:** ALDO DAVID CRUZ JAIMES
**Objetivo:** Desarrollar un sistema de gestión para una biblioteca escolar que soporta títulos con cantidades irregulares de ejemplares, aplicando algoritmos manuales de ordenamiento por inserción y búsqueda binaria.
**Estructura de carpetas:**
- `/src`: Código fuente en C#
- `/docs`: Documentos de diseño y anexos.
